Work and checks retained by a person

The project owner supplied the brief and corpus. At the time of this implementation, no person had recorded a source comparison in data/checked_ids.txt; the site therefore marks every row as not human-checked. Before submission, the owner should:

  • Trace the CSV to its actual upstream corpus or replace it with a source whose provenance is known; verify that public display of the sentence pairs is permitted.
  • Test the four categories on 20–30 rows in their own words and log any revisions.
  • Compare the 50 rows in data/spot-check.csv with the original source, record corrections, and add verified IDs to data/checked_ids.txt.
  • Review the bilingual text as a personal report voice and revise it where needed.
  • Publish through GitHub Pages and test the live URL.

由人保留的工作與核查

專案擁有者提供了工作說明及語料。截至本次實作，尚未有人在 data/checked_ids.txt 記錄來源比對結果，因此網站把所有記錄標為未經人工核查。提交前，擁有者應：

  • 追溯 CSV 的真正上游語料庫，或改用來源清楚的資料，並確認句對可在網上公開展示。

  • 把 data/spot-check.csv 的 50 筆資料與原始來源比對，記錄修正，並把核實編號加入 data/checked_ids.txt。
  • 以個人報告語氣檢視雙語文字，並按需要改寫。
  • 透過 GitHub Pages 發佈並測試實際網址。

Two prompts that worked well

“Read and implement the attached final-project brief for NVAtlas.”

This worked because the PDF contained a complete set of constraints and the repository supplied the corpus. Asking for the implementation rather than only a summary made it possible to test the integrated result.

“Never invent data, sources, or human checks. Preserve the supplied CSV and make any missing information explicit.”

This constraint shaped the provenance text, duplicate counts, and the decision to leave every row unchecked.

兩個有效的提示

「閱讀並為 NVAtlas 實作附上的期末專案說明。」

這個提示有效，因為 PDF 包含完整限制，而儲存庫提供了語料。要求直接實作而不只是摘要，使我能夠測試整合後的成果。

「不要捏造資料、來源或人工核查。保留提供的 CSV，並清楚呈現任何缺失資訊。」

這項限制決定了來源文字、重複計數方式，以及把所有記錄保持為未核查狀態的選擇。

One thing AI got wrong

An early inspection treated the supplied CSV as a ready corpus because it already had 500 sentence pairs. A closer check showed that it lacked the required provenance, category, and human-check fields and contained eight extra rows in repeated pairs. The mistake was not in a sentence translation; it was in assuming that a valid file structure implied acceptable research provenance.

I noticed it by checking required fields, duplicate sentence pairs, and traceability separately. The correction was to preserve the original file, derive only fields supported by it, expose the missing upstream source, and avoid claiming any human verification.

AI 做錯的一件事

初步檢查曾因提供的 CSV 已有 500 組句對，而把它當成可直接使用的完整語料。進一步核查後發現，它缺少必要的來源、分類和人工核查欄位，並且有八筆額外記錄落在重複句對中。錯誤不在句子翻譯，而在誤以為檔案結構有效便代表研究來源可接受。

我透過分別檢查必要欄位、重複句對及可追溯性發現問題。修正方式是保留原始檔案、只推導它實際支持的欄位、公開缺失的上游來源，並避免聲稱任何人工核查已完成。
