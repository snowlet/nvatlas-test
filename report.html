Origin

I chose nominal-to-verbal translation as the topic because the department’s NV Atlas shows how a corpus becomes easier to reason about when words, contexts, and relationships are linked rather than buried in separate tables. The supplied CSV made this question concrete: every row gives an English sentence, a Chinese sentence, one English key noun, and one Chinese verb correspondence.

The project therefore asks a narrow question that the data can actually support. It does not claim to judge every word in each translation. It examines the supplied noun–verb pair as a visible point of grammatical and lexical change.

起源

我選擇「名詞轉為動詞」作為題目，是因為翻譯系的 NV Atlas 展示了：當詞語、上下文和關係互相連結，而不是分散在表格裡，語料會更容易理解。提供的 CSV 使問題變得具體：每一筆資料都包含一個英文句子、一個中文句子、一個英文關鍵名詞，以及一個中文動詞對應。

因此，本專案只提出資料真正能回答的窄問題。它不以判定整句翻譯的每個詞為目標，而是把提供之名詞—動詞組合作為觀察語法與詞彙轉換的入口。

Background

English academic and narrative prose often uses nominalizations: permission, decision, attention, and protection package an action inside a noun. Chinese can preserve a noun in some contexts, but it also frequently uses a verb or verb-like expression where English uses a noun. This possibility of grammatical recoding is central to translation shifts and transposition.

The codebook operationalizes that broad idea through observable word form. It separates action/process nominalizations, result/product nominalizations, state/quality nominalizations, and nouns without one of the tested derivational endings. The categories are a starting point for comparison, not a proof that every Chinese item is the only possible equivalent.

背景

英文學術與敘事文本常用名詞化，例如 permission（允許）、 decision（決定）、attention（注意）和 protection（保護），把動作壓縮成名詞。中文有時保留名詞，但也經常在英文使用名詞之處改用動詞或類動詞表達。這種語法重編碼與翻譯轉移、詞類轉換密切相關。

分類手冊把這個大概念落實為可觀察的詞形：動作／過程名詞化、結果／成品名詞化、狀態／性質名詞化，以及沒有採用上述可測後綴的詞根式名詞。這些類別是比較的起點，不是對唯一等效譯法的證明。

Gap

Corpus dashboards often make counts look more authoritative than the records behind them. This project addresses a smaller but important gap: users need to move from a pattern to an aligned sentence, from an aligned sentence back to a category, and from both to an honest statement of provenance.

The supplied file has no upstream corpus name, URL, or original sampling seed. It also contains eight extra rows that repeat a sentence pair. The site records those limits instead of repairing them through guesswork. A second unresolved gap is human verification: no row can responsibly be marked human_checked = yes until a person compares it with the original source.

研究缺口

語料儀表板常讓統計數字看起來比背後的記錄更權威。本專案處理一個較小但重要的缺口：使用者需要能從模式走到對齊的句子、從句子回到分類，並從兩者連到誠實的來源說明。

提供的檔案缺少上游語料庫名稱、網址及原本的取樣種子，另外有八筆額外記錄重複了句對。網站保留這些限制，而不是靠猜測修補。第二個未解缺口是人工核查：在任何資料與原始來源比對之前，不應負責任地把 human_checked 標成 yes。

Questions

  1. Which English key nouns recur most often in the supplied pairs?
  2. How do the four form-based categories vary by English sentence length?
  3. Which noun–verb correspondences form the strongest repeated links?
  4. Can search and linked views keep the visual patterns accountable to individual sentences?

研究問題

  1. 提供的句對中，哪些英文關鍵名詞最常重複出現？
  2. 四個按詞形定義的類別如何隨英文句子長度變化？
  3. 哪些名詞—動詞對應形成最強的重複連線？
  4. 搜尋與互相連結的檢視能否讓視覺模式持續對應到個別句子？

Method

The source is NVAtlas-AI-Agent.csv, supplied on 5 November 2026. All 500 rows are retained in source order. The structure of the input is independently checked: there are 500 unique record IDs, 492 unique sentence-pair strings, and eight extra rows in repeated pairs. Categories are assigned by an ordered suffix rule, so rerunning the build produces the same labels.

For the required manual check, the build script draws 50 records with fixed seed 2026 and writes them to data/spot-check.csv. That list is intentionally still pending. Once a person compares each row with the original source, verified IDs can be added to data/checked_ids.txt and the corpus can be rebuilt. The codebook log records no post-test revisions yet because the 20–30 row human test has not been completed.

方法

資料來源是 2026 年 11 月 5 日提供的 NVAtlas-AI-Agent.csv。500 筆記錄全部按原順序保留。輸入結構另行檢查：共有 500 個唯一記錄編號、492 個不重複句對字串，重複句對中有八筆額外記錄。分類採用有先後次序的後綴規則，因此每次重建都會產生相同標籤。

為執行要求的人工檢查，建置腳本用固定種子 2026 抽取 50 筆記錄，寫入 data/spot-check.csv。該清單刻意保持待核查狀態。當有人把每一筆與原始來源比對後，可把已核實編號加入 data/checked_ids.txt，再重建語料。分類手冊的變更日誌目前尚未記錄測試後的修訂，因為 20–30 筆人工測試仍未完成。

Analysis

The noun–verb network is the first entry point into repetition. In the full corpus, attention is the most frequent English key noun, occurring 45 times; its Chinese correspondence 注意 occurs 42 times. This gap is already analytically useful: repeated source language does not guarantee a perfectly one-to-one extracted target term. The other strong clusters include permission, protection, vacation, performance, and question-related actions.

The Term-in-context view then tests those frequencies against aligned sentences. Selecting a node or keyword chip opens its source and target contexts, so a repeated pattern cannot remain detached from the row that produced it.

分析

「名詞–動詞網絡」是觀察重複模式的第一個入口。在完整語料中，attention 是最頻繁的英文關鍵名詞，共出現 45 次；其中文對應詞注意出現 42 次。這個差距本身已有分析價值：原文詞語的重複不一定保證抽出的譯文詞語完全一對一。其他明顯的詞群包括 permission、protection、vacation、performance 以及與 question 有關的動作。

接著，「詞語與上下文」檢視把頻率放回對齊句子中。點選網絡節點或關鍵詞標籤後，便會顯示原文和譯文上下文，使重複模式不能脫離產生它的記錄。

The Category composition figure shows a corpus dominated by action/process nominalizations, as expected from the concentration of words ending in -tion and -sion. The Category by source length view asks whether this form-based profile changes with sentence length. Any interpretation should remain provisional: the source lacks upstream provenance, repeated pairs inflate some counts, and the human quality check is outstanding.

The Corpus data table provides the record-level audit trail behind all three views: sorting, filtering, keyword links, and CSV export all use the same current record set.

「類別構成」圖顯示語料以動作／過程名詞化為主，這與大量 -tion、-sion 字尾詞相符合。「類別與原文長度」檢視進一步詢問這個按詞形得出的概況是否隨句長改變。任何解讀都應暫時保守：來源缺少上游說明、重複句對會放大部分次數，而且人工品質核查仍未完成。

「語料資料」表格提供三個檢視背後的逐筆稽核路徑：排序、篩選、關鍵詞連結和 CSV 匯出都使用同一組目前記錄。

Conclusion

The executable result is a complete static corpus explorer with search, category and review-status filters, three linked analytical views, an exportable table, bilingual interface text, a published codebook, a learning report, and an AI-use declaration. The strongest visible pattern is the repeated mapping of abstract English nominalizations to compact Chinese verbs, especially around attention.

That finding remains a data description rather than a final claim about translation norms. The next meaningful step is human source verification, followed by correction of any mismatched sentence pairs and a revision of the codebook after its first small test.

結論

本次交付的成果是一個完整的靜態語料探索器，包含搜尋、類別及核查狀態篩選、三個互相連結的分析檢視、可匯出的表格、雙語介面、已發佈的分類手冊、學習報告與 AI 使用聲明。最明顯的視覺模式，是抽象英文名詞化重複對應到精簡的中文動詞，尤其在 attention 一詞周圍最突出。

這項發現目前只是資料描述，不是對翻譯規範的最終結論。下一步應由人工核對原始來源，修正任何不對應的句對，並在第一次小規模測試後修訂分類手冊。

Reflection

The most important difficulty was not drawing charts. It was deciding what claims the input could support. A working interface can hide data problems behind polished totals. Building provenance fields, duplicate-group counts, a fixed review sample, and the same filter state across every view made those gaps harder to ignore.

AI was useful for translating the brief into an implementation plan, generating the static code, mapping fields, and testing interactions. It could not supply the missing upstream source or perform the person’s required manual evaluation. I would next test the category rules on 20–30 rows before scaling up, and I would collect provenance at the same moment as each sentence pair rather than trying to recover it later.

反思

最大的困難並非畫圖，而是判斷輸入資料足以支持哪些結論。一個運作正常的介面可能用精緻的統計數字掩蓋資料問題。建立來源欄位、重複群組計數、固定核查樣本，以及讓每個檢視共用同一篩選狀態，能使這些缺口較難被忽略。

AI 能協助把工作說明轉成實作計劃、產生靜態程式碼、映射欄位及測試互動，卻不能補回缺失的上游來源，也不能代替學生完成必要的人工評估。下一步應先以 20–30 筆記錄測試分類規則，再擴大規模；日後也應在收集每個句對的同時記錄來源，而不是事後設法補救。
